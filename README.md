# DSH-ARCHIVE

DSH-ARCHIVE 是一个基于 DSH 框架、可长时间自主运行的智能体系统：具备跨会话的长期记忆、可成长的虚拟人格与主动思考循环，能在无人值守时自主决策、定时执行任务并向你汇报，并提供一套网页控制台查看与调整全部状态。

## 模块组成

- **记忆系统（memory）**：跨会话全局记忆，对话与事件自动写入 SQLite + 向量库，语义与关键词混合检索；维护用户画像与当前状态（带过期）。
- **人格系统（persona）**：虚拟人格的权威存储与留档账本，支持逐条修改与整体重建、历史版本回滚，以及用 LLM 一键凝练整理全部人格条目。
- **虚拟时钟（clock）**：长驻循环的唯一时间源（年月日 + 24 小时制），保证定时与记忆时间戳一致。
- **自循环思考（loop）**：事件触发 + 定时兜底的主动思考驱动器，每轮结合记忆/状态/人格分析场景并决定行为（是否发言、是否行动、是否告知）；带睡眠/清醒期、发言限频与行动预算等防护。
- **自进化（evolution）**：对人格与技能生成改进候选 → 隔离评估 → 由你授权采纳或拒绝，可每日自动生成候选并提醒。
- **人格一致性（consistency）**：滑动窗口跟踪人格轨迹并拦截突变漂移，让人格稳定演进而不走样。
- **潜意识·梦境引擎（subconscious）**：睡眠期后台运行，凝缩高频记忆、异质碰撞生成灵感草案。
- **定时任务（schedule）**：告诉 AI 几点做什么，到点自动发消息或执行。
- **主动消息（notify）**：AI 主动消息的通知栏与流水记录（限频防打扰）。
- **总控界面（control）**：专属网页控制台，提供总控、人格、思维循环、记忆、自进化、定时任务、通知、识图等功能页，以及提示词与报错记录面板。
- **支撑模块**：ledger（提示词/报错全量记录）、web-perf（页面与静态资源缓存优化）、web-fetch（宿主侧网页抓取，供检索工具使用）、识图（图像理解入口，依赖视觉模型）。

## 部署指南

### Windows

1. 前置：Node.js ≥ 22.5、pnpm（首次安装脚本会在缺失时自动处理）。**无需单独安装 DSH**——本项目自带运行所需组件，与其它 DSH 环境相互独立。向量模型运行时 [ollama](https://ollama.com)：首次安装脚本会自动处理——本机已运行 ollama 则直接复用并补拉嵌入模型；否则自动下载捆绑版（约 1.3GB）并在首次启动时自动拉取嵌入模型 `shaw/dmeta-embedding-zh`（下载失败不影响其余步骤，可按提示稍后手动补齐）。
2. 下载代码：`git clone https://github.com/ACTXY1/DSH-ARCHIVE-1.git`（或页面 Code → Download ZIP）。
3. 首次安装：双击根目录《首次安装或移动项目位置点我.cmd》（检测/提示前置环境、安装依赖、同步插件并建立运行入口）。首次安装需要联网一次，用于下载项目依赖。
4. 配置模型密钥：启动后浏览器进入控制台 → 模型页填写 API Key（或配置自定义提供商）；未配置时服务可启动，AI 相关功能会提示缺少凭据。
5. 启动：《启动DSH-ARCHIVE.cmd》，访问 http://127.0.0.1:3081。
6. 更新：《一键更新.cmd》从本仓库拉取最新版本（匿名只读）；《一键回滚.cmd》回到上一版本。更新不触碰 `dsh\data`（记忆/会话/凭据）与 ollama 模型。停止用《停止DSH-ARCHIVE.cmd》。

### 说明

- 用户数据目录 `dsh\data` 与 ollama 模型库不进入仓库、不参与一键更新，可安全删除后重装。
- 项目运行所需的组件随项目自身依赖提供，安装后不再依赖系统中其它 DSH 环境的版本；其它 DSH 环境升级、卸载或调整，不影响本项目。
- 项目文件夹可以整体移动；移动后在新的位置运行一次《首次安装或移动项目位置点我.cmd》即可继续使用（对话记录、记忆与模型配置随文件夹一起保留）。
- 默认仅监听 127.0.0.1（本机访问）；如需局域网访问请参照系统级端口转发方式自行配置。
